# FM 커리어 아카이브

Football Manager 의 **내보낸 팀 파일(.fmf)** 과 **세이브(.fm)** 를 읽어
지난 시즌의 커리어 연표를 만들어 보여 줍니다.

## 어떻게 쓰나

<https://halojh.github.io/fm-archive-web/> 를 열고
Football Manager 폴더를 끌어다 놓으면 됩니다. 설치도 로그인도 없습니다.

## 파일은 올라가지 않습니다

해독과 화면 그리기가 **전부 브라우저 안에서** 끝납니다. 서버가 없습니다.
이 주소는 페이지 파일 한 장(약 120KB)만 내려줍니다.
세이브 파일은 네트워크로 나가지 않습니다.

## 무엇이 나오나

- 세이브 연대기 — 어느 구단에서 몇 시즌을 보냈나
- 성장 곡선 — 시즌별 스쿼드 능력치 평균과 최고
- 홈구장의 역사 · 재직 기간 · 이적 흐름
- 시즌별 스쿼드와 선수 카드

세이브 파일까지 같이 있으면 세이브 이름과 날짜가 붙습니다.

## 만든 것

`index.html` 한 장이 전부입니다. 바깥에서 받아오는 것은 글꼴뿐입니다.
