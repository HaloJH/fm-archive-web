# FM 커리어 아카이브

Football Manager 의 **세이브(.fm)** 와 **내보낸 팀 파일(.fmf)** 을 읽어
지난 시즌의 커리어를 되살려 보여 줍니다.

## 어떻게 쓰나

<https://halojh.github.io/fm-archive-web/> 를 열고
Football Manager 폴더를 끌어다 놓으면 됩니다. 설치도 로그인도 없습니다.

## 파일은 올라가지 않습니다

해독과 화면 그리기가 **전부 브라우저 안에서** 끝납니다. 서버가 없습니다.
이 주소는 페이지 파일 한 장만 내려줍니다. 세이브 파일은 네트워크로 나가지 않습니다.

## 무엇이 나오나

### 내보내기가 없어도 — 세이브 하나면 됩니다

이게 이 도구의 핵심입니다. `.fm` 파일 하나만 있으면 이만큼이 나옵니다.

- **시즌 연표** — 순위 · 승무패 · 득실 · 승점, 몇 부에 있었는지
- **컵 여정** — 몇 강까지 갔는지, 결승 상대는 누구였는지
- **트로피 진열대** — 시즌마다 우승과 준우승
- **감독 재임** — 언제 어느 구단을 맡았는지 (국가대표 겸직 포함)
- **수상과 포디움** — 누가 무슨 상을 받았는지, 1·2·3위까지
- **월드컵 · 아시안 컵** — 역대 우승국

400MB 세이브를 통째로 열지 않습니다. 파일 꼬리로 목록을 읽고
**필요한 부분만** 떠옵니다.

### 내보낸 팀 파일이 있으면 더

- 선수 이름과 능력치, 시즌별 스쿼드와 선수 카드
- 성장 곡선 — 같은 선수를 여러 시즌 따라간 현재능력
- 구장 · 관중 · 계약 같은 구단 정보

### 없는 것은 없다고 합니다

자료가 없는 칸은 **채우지 않고 비웁니다.** 무엇이 있어야 그 칸이 나오는지
화면이 직접 알려 줍니다. 이름을 모르는 사람은 번호로 남겨 둡니다 —
없는 이름을 지어내지 않습니다.

## 한계

- **FM24 로만 확인했습니다.** 다른 버전은 자료 배치가 달라 안 될 수 있습니다.
  배치가 다르면 그 칸을 통째로 건너뜁니다 — 틀린 값을 보여 주지는 않습니다.
- 구단·선수 **이름**을 붙이려면 세이브 안의 큰 구획을 더 읽어야 합니다(느립니다).
  안 읽는 길도 함께 있습니다.
- 대회 **이름**은 세이브 안에 없습니다. 라운드 번호가 해마다 바뀌기 때문입니다.
  화면 캡처 같은 정답지가 있어야 이름이 붙습니다.
