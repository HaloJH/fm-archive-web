# FM 커리어 아카이브

Football Manager 의 **세이브(.fm)** 와 **내보낸 팀 파일(.fmf)** 을 읽어
지난 시즌의 커리어를 되살려 보여 줍니다.

## 어떻게 쓰나

<https://halojh.github.io/fm-archive-web/> 를 열고
Football Manager 폴더를 끌어다 놓으면 됩니다. 설치도 로그인도 없습니다.

플레이스루 카드가 뜨면 **카드를 누르세요.** 감독 · 구단 · 선수 세 탭으로
커리어 한 장이 만들어집니다. 세이브에서 필요한 부분만 떠오느라 20초쯤 걸리고,
그동안 무엇을 읽고 있는지 진행 막대가 알려 줍니다. 한 번 만들면 다음부터는 바로 뜹니다.

## 파일은 올라가지 않습니다

해독과 화면 그리기가 **전부 브라우저 안에서** 끝납니다. 서버가 없습니다.
이 주소는 페이지 파일 한 장만 내려줍니다. 세이브 파일은 네트워크로 나가지 않습니다.

## 무엇이 나오나

### 내보내기가 없어도 — 세이브 하나면 됩니다

이게 이 도구의 핵심입니다. `.fm` 파일 하나만 있으면 이만큼이 나옵니다.

- **시즌 연표** — 순위 · 승무패 · 득실 · 승점, 몇 부에 있었는지
- **컵 여정** — 몇 강까지 갔는지, 결승 상대는 누구였는지
- **트로피 진열대** — 시즌마다 우승과 준우승
- **감독 재임** — 언제 어느 구단을 맡았는지 (국가대표 겸직 포함)
- **수상과 포디움** — 누가 무슨 상을 받았는지, 1·2·3위까지
- **월드컵 · 아시안 컵** — 역대 우승국

구단을 옮겨 다닌 커리어는 **재임 기간에 맞춰 이어 붙입니다** — 그해 맡고 있던
구단의 성적과 트로피가 나옵니다. 남의 구단 기록을 내 연표에 섞지 않습니다.

400MB 세이브를 통째로 열지 않습니다. 파일 꼬리로 목록을 읽고
**필요한 부분만** 떠옵니다.

### 내보낸 팀 파일이 있으면 더

- 선수 이름과 능력치, 시즌별 스쿼드
- **선수를 누르면 카드** — 받은 상과 해마다 오른 1·2·3위
- 성장 곡선 — 같은 선수를 여러 시즌 따라간 현재능력
- 구장 · 관중 · 계약 같은 구단 정보

### 트로피 사진

트로피 메가팩을 쓰고 계시면 그 팩의 **종류별 트로피 그림**이 붙습니다.
페이지가 그림을 들고 있는 게 아니라 **여러분 폴더에 있는 것을 읽습니다.**
팩이 없으면 직접 그린 도형이 나옵니다.

### 없는 것은 없다고 합니다

자료가 없는 칸은 **채우지 않고 비웁니다.** 무엇이 있어야 그 칸이 나오는지
화면이 직접 알려 줍니다. 이름을 모르는 사람은 번호나 성으로 남겨 둡니다 —
없는 이름을 지어내지 않습니다. 진행 막대도 같습니다: 잴 수 있는 단계만 채우고,
못 재는 단계는 줄무늬로 두고 "얼마나 남았는지는 못 잽니다" 라고 적습니다.

## 한계

- **FM24 로만 확인했습니다.** 다른 버전은 자료 배치가 달라 안 될 수 있습니다.
  배치가 다르면 그 칸을 통째로 건너뜁니다 — 틀린 값을 보여 주지는 않습니다.
- 대회 **이름**은 세이브 안에 없습니다. 라운드 번호가 해마다 바뀌기 때문입니다.
  (리그 이름은 있습니다. 컵 이름이 없습니다.) 화면 캡처 같은 정답지가 있어야 이름이 붙습니다.
- 디비전 이름표가 **잉글랜드 기준**입니다. 다른 나라 리그는 번호로 나올 수 있습니다.
- 수상자의 **전체 이름**은 세이브에 다 들어 있지 않습니다. 모르는 사람은 성으로 남습니다.
